# Changelog

All notable changes to this project are documented here.
Format: [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/) · [SemVer](https://semver.org/).
New entries are appended at the bottom.

## [1.0.0] - 2026-10-26

### Added
- First version, based on the Catppuccin Mocha `portfolio.html` design from Drive `Development/portfolio`.
- Hero, Resume (education, certifications, skills, experience) and Projects sections, updated from the 2026 resume.
- Project cards built from `js/projects.js` so new projects are a single entry.
- Contact dialog with LinkedIn and GitHub links (replaces the demo form, which did not send anything).
- Phone-width layout fixes.

## [1.1.0] - 2026-10-26

### Added
- Email contact: Gmail and Proton Mail buttons in the contact dialog (open your mail app), plus an EMAIL link in the footer.

## [1.2.0] - 2026-10-26

### Added
- Tactical GPS as the first project card, with GitHub and Download APK buttons.
- MIT `LICENSE` file and a License section in the README.
